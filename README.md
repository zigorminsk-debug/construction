# Construction — Конструктор раскроя

**Программа для расчета раскроя листового материала по принципу PRO100.**

Автоматически рассчитывает размеры всех деталей с учётом зазоров, кромок и толщины материала, рисует эскизы изделия в сборе и в проекциях, строит карты раскроя на лист и смету.

### 📖 Справка — пошаговая инструкция

Полная инструкция также есть в приложении: кнопка **❓** в шапке.

**Шаг 1. Тип изделия.** Нажмите карточку: Шкаф, Тумба, Стойка (стеллаж), Стол, Полка или Металл (рама из профиля).

**Шаг 2. Габариты и материал.** Введите высоту H, ширину W, глубину D (мм). Выберите материал (ЛДСП/МДФ/фанера/ОСП/ДСП) и толщину — размер листа подставится автоматически. Нестандартный лист — блок «Мой материал»: своё название, толщина, размер листа, цена, кнопка «＋ Добавить». При необходимости отметьте «Задняя стенка ДВП» и «Цоколь».

**Шаг 3. Наполнение.** Настройте сборку корпуса (вкладная/накладная), количество полок, дверей, ящиков, перегородок, зазор фасада и отступ полки. Для стола — тип опор. Для любого корпуса доступен чекбокс **«Металлический каркас (профтруба)»**: 4 стойки по углам + нижние рамы, выбор сечения, крепление болтами M6 (разметка отверстий — в карточках деталей).

**Шаг 4. Результат — 6 вкладок:**
1. **Сборка (3D)** — эскиз; ⟲ поворот, «в разнос», «отверстия»; клик по детали — позиция, повторный клик — карточка; тап по пустому месту — полный экран (щипок/двойной тап — зум).
2. **Чертежи** — 4 вида (фасад, сбоку, сверху, изометрия).
3. **Детали** — спецификация: колонка **⚖️ Нагрузка** — максимальная нагрузка на полку (по толщине, пролёту, глубине, материалу); колонка **🕳 Разметка** — число отверстий (клик — карточка с нумерованной разметкой); 📋 — карточка детали: позиция в изделии, развёртка (раскрой) с разметкой отверстий, крепёж.
4. **Крепёж** — все соединения: какие детали, чем и в каком количестве крепятся.
5. **Раскрой** — нестинг по листам (эффективность %), раскрой металлического профиля.
6. **Смета** — материалы, фурнитура, работа, итог.

**Шаг 5. Экспорт.** 🖨️ — печать/PDF (все вкладки подряд на белом фоне); ⬇ CSV — список деталей для ЧПУ; ⎘ — список в буфер обмена; 💾 — сохранить проект в браузере.

**Мобильная версия (APK).** Переключатель «Параметры/Результат»; кнопка «назад» закрывает зум и карточку, а затем приложение. При запуске приложение само проверяет GitHub Releases — при новой версии предлагает скачать и установить (однократно нужно разрешить «установку из неизвестных источников»).

### 🪚 Возможности

- **Типы изделий:** Шкаф, Тумба/Комод, Стойка/Стеллаж, Стол, Полка, **Металлическая рама из профиля**
- **Параметры:** высота/ширина/глубина, кол-во полок, дверей, шуфлядок (ящиков), вертикальных перегородок
- **Материалы:** ЛДСП 16/18, МДФ 16/18, Фанера 12/15/18/21, ОСП/OSB 12/15, ДСП 22 + ДВП 3.2 на заднюю стенку
- **Конструкция:** вкладная / накладная (крыша и дно между боковин или сверху), задняя стенка, цоколь, зазоры фасадов, отступ полки
- **Расчёт:** все детали с чистовыми размерами, кромка, припуск на пропил 3 мм, площадь, погонаж кромки
- **Эскизы:**
  - Сборка — изометрия (3D), фасад, вид сбоку + режим «в разнос»
  - 4 проекции — спереди, сверху, сбоку, развёртка задней стенки
  - Эскиз каждой детали с размерами и кромкой
- **Кликабельные детали:** клик по строке списка / эскизу / детали в сборке — деталь подсвечивается в изометрии с указанием её позиции (размер, отверстия, примечание)
- **📋 Карточка детали:** развёртка (раскрой) детали с **разметкой отверстий под крепёж** (Ø, глубина, грань, координаты), мини-3D с позицией в изделии и список соединений «к какой детали и чем крепится»
- **🔩 Вкладка «Крепёж»:** все соединения конструкции (шканты, минификсы, саморезы, петли, полкодержатели), суммарное количество крепежа по типам, детали с разметкой отверстий
- **🏗️ Металлическая рама:** основная конструкция из прямоугольного профиля (20×20…60×30, стенка 1.5–3 мм): уровни рам, перегородки, листовые полки, задняя стенка. Крепление — болты M6 (Ø6.6) + угольники. Отдельный раскрой профиля (метраж, вес, цена), смета на металл
- **Раскрой:** автоматическая укладка деталей на листы (алгоритм Shelf + поворот), эффективность, обрезь, карты раскроя SVG с линиями реза
- **Смета:** материалы (лист × цена/м², профиль × цена/м), кромка, фурнитура (петли, направляющие, ручки, конфирматы, болты M6, угольники), работа (раскрой, кромление, присадка, сверление) + итог
- **Экспорт:** CSV, печать, копирование спецификации, сохранение проекта в браузере

### 📱 APK — Android

Проект собирается в **APK** автоматически на GitHub Actions.

#### Скачать APK

1. Открой вкладку **Actions** в репозитории → выбери последний успешный `Build APK`
2. Скачай артефакт `construction-release-apk` → внутри `construction-v1.0.X.apk` (подписанный, рекомендуемый)
   или `construction-debug-apk` → `app-debug.apk`
3. На телефоне разреши «Установку из неизвестных источников» и установи

> При пуше в `main` создаётся **Release** с прикреплёнными APK (тэг `v1.0.<run_number>`).
>
> ✅ Все сборки подписаны **перманентным ключом** из репозитория, а `versionCode` растёт с каждым запуском CI —
> новое APK **устанавливается поверх** уже установленного (просто перезапустите установку).
>
> ⚠️ **Один раз** пользователям старых сборок (до введения перманентного ключа) придётся
> **удалить старое приложение** и поставить новое — оно было подписано другим (автогенерируемым) ключом.

#### Собрать локально

```bash
npm install
npm run build            # соберёт dist/

# Скопировать в Android
rm -rf android/app/src/main/assets/www
mkdir -p android/app/src/main/assets/www
cp -r dist/* android/app/src/main/assets/www/

# Собрать иконки (PWA + Android mipmap) — из выбранного варианта
node scripts/make-icons.js

# Собрать APK (требует JDK 17 + Android SDK)
cd android
./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

### 🔑 Подпись APK (перманентный ключ)

Все сборки — **debug и release, CI и локальные** — подписываются ОДНИМ и тем же
перманентным ключом, который лежит в репозитории:

| Параметр | Значение |
|---|---|
| Файл | `android/keystore/construction-release.p12` (PKCS#12) |
| Alias | `construction` |
| Пароль | `construction-key-2026` |
| Действителен до | **2054-02-05** |
| SHA-256 отпечаток | `D0:E2:78:…:3E:4A` (полный — в `android/keystore/cert-sha256.txt`) |

Почему так: Android обновляет приложение **только по тому же сертификату**.
Ключ один на всех (любой агент, любая сборка) + растущий `versionCode`
(`-PciVersionCode=<номер запуска CI>`) = обновление «поверх» установленного.

**Правила (и для агентов):**
- ❌ Никогда не генерировать новый ключ и не использовать автогенерируемый `debug.keystore`
- ❌ Не менять пароль/alias — только `-PciVersionCode` и иконки
- ✅ Локальная release-сборка: `./gradlew assembleRelease -PciVersionCode=NNN`
  (NNN — больше, чем у последней опубликованной версии)
- ✅ Проверка подписи: `apksigner verify --print-certs *.apk` → отпечаток совпадает с `cert-sha256.txt`

Полная документация ключа: [`android/keystore/README.md`](android/keystore/README.md).

### 🧩 Логика расчёта (как в PRO100)

- **Боковины** = `H × D` (2 шт), **Крыша/Дно** = `(W-2t) × D` (вкладные) или `W × D` (накладные)
- **Полка** = `(W-2t - зазоры) × (D - отступ_фасада)` , кромка «перед»
- **Дверь** = `(W - (N+1)*зазор)/N  ×  (H - цоколь - 2*зазор)` , зазор 3 мм, петля 35 мм
- **Ящик**: фасад `W-2*зазор × (H_ящ)`, короб `W-26 × D-30 × H120`, дно ДВП
- **Задняя стенка ДВП** = `(W-6) × (H-6)` , в паз 10 мм или накладная
- **Кромка**: по периметру / перед / 2 длинных — считается в погонаж
- **Раскрой**: сортировка по убыванию, укладка «полками» с учётом пропила 3 мм и поворота 90°
- **Металлическая рама**: 4 стойки `H`, на каждом уровне 2 рамы фронт/бэк `W-2pw` и 2 боковые `D-2ph` (pw/ph — габариты профиля), перегородки `H-2pw`, листовые полки на уровнях. Профиль не идёт в раскрой листа — отдельный список отрезков с метражем и весом.

Толщина материала влияет на все внутренние размеры — меняйте её в селекторе.

### 🔩 Крепёж и разметка отверстий

Модуль `joinery.js` строит 3D-раскладку каждой детали и автоматически назначает крепёж по типам соединений:

| Соединение | Крепёж | Разметка |
|---|---|---|
| Боковина ↔ крыша/дно (вкладная) | шкант Ø8×40 + клей | 2 шт, 30 мм от кромок, 35 мм от торца |
| Боковина ↔ крыша/дно (накладная) | шкант Ø8×30 + саморез Ø4×40 | из торца + сверху |
| Полка ↔ боковина (вкладная) | минификс (конфирмат + шкант) | Ø15 в торце полки, шкант в боковине, 40 мм от фасада |
| Полка ↔ боковина (накладная) | полкодержатель Ø5×60 | 3 шт на боковину |
| Перегородка ↔ крыша/дно | шкант Ø8×30 | 2 сверху + 2 снизу |
| Задняя ДВП ↔ боковины | саморез/гвоздь Ø3.5×40 | 3 шт через торцы |
| Дверь ↔ корпус | петля 35 мм (конфирмат Ø35) | 2 шт на дверь, 20 мм от краёв |
| Короб ящика | саморез Ø4×40 / Ø3.5×16 | 4 на короб + 3 на направляющие |
| Стойка ↔ рама (металл) | болт M6 (Ø6.6) + угольник | по 1–2 на соединение, 10 мм от кромок |
| Полка ↔ рама (металл) | саморез по металлу Ø4×13 | 4 шт на полку |

Каждое отверстие имеет тип, диаметр, глубину, грань и координаты — рисуется на развёртке детали (в карточке 📋) и точками на гранях в сборке (кнопка «🔩 Отверстия»).

### 🔧 GitHub Actions — как работает «Автоматически создавай APK»

Workflow `.github/workflows/build-apk.yml` триггерится на `push` в `main` и на `workflow_dispatch`:

1. `setup-node` → `npm ci` → **`node scripts/make-icons.js`** (иконки из `icons/app/app-icon.json`) → `npm run build` (Vite)
2. копирует `dist/*` → `android/app/src/main/assets/www/`
3. `setup-java 17` + `setup-android` → `gradle assembleDebug` и `assembleRelease`
   — обе подписаны перманентным ключом из `android/keystore/`,
   `versionCode = github.run_number` (растёт → обновление «поверх»)
4. `apksigner verify` — проверка, что подпись совпадает с `android/keystore/cert-sha256.txt`
5. APK в **Artifacts** (`construction-release-apk`, `construction-debug-apk`)
6. при пуше в `main` создаёт **Release** с обоими APK (тэг `v1.0.<run_number>`)

Никаких секретов не требуется — ключ лежит в репозитории, используется `GITHUB_TOKEN`.

### 📐 Точность

- Размеры округляются до 1 мм, площадь до 0.001 м²
- При расчёте раскроя к чистовому размеру добавляется припуск кромки (`+0.5 / +1 / +2 мм`)
- Пропил 3 мм заложен между деталями
- Эффективность = `площадь_деталей / площадь_листов ×100%`

> Для производства всегда проверяйте припуски на кромку и направление волокон.
